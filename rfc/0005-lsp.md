# RFC 0005 — lsp

Status: Accepted (MVP)

## Problem

IntelliSense must not wait on a full Luau emit. Editors should query a semantic model.

## Syntax

N/A. The language service parses with recovery (`parse_for_ide`) so a broken file still yields completions.

## Semantics

`CompilerApi` / `Session`:

| Query | Role |
| --- | --- |
| `check` / `check_source` | parse, bind, resolve, module graph, diagnostics |
| `get_symbol` | symbol at line + name |
| `get_type` | `TypeId` after flow |
| `get_members` | struct/API members |
| `get_definition` | file + line/col |
| `get_diagnostics` | syntax + semantic, not emit errors |
| `type_of_expr` | prefix type for completion |

## AST

LSP never mutates AST for codegen. `src/lsp` re-exports `analysis` as `service`.

## Binder / Symbols

Completion of `@` / `.` / `~>` reads bound `self` and checker members.

## Types

Typed member completion uses `session::members_of`.

## Diagnostics

Published on change; codes from `src/diagnostics`.

## LSP

`src/lsp/server.rs` — **adapter only** via [`tower-lsp-server`](https://crates.io/crates/tower-lsp-server) (JSON-RPC framing + `LanguageServer` trait). Hover, definition, completion call `analysis` / `CompilerApi`. Do not re-implement `Content-Length` or JSON-RPC by hand. Format/rename stay in `analysis` / `fmt`. Incremental query engine is RFC 0006.

See also [docs/architecture/DONT_REINVENT.md](../docs/architecture/DONT_REINVENT.md).

## Codegen

Must not run inside `clpp lsp` request handlers.
