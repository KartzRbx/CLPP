Stdlib

Headers under stdlib/clpp. Angle-bracket includes are IntelliSense (and require for libs).

Include Effect Page
<clpp/roblox.clh> engine globals, IntelliSense only roblox.clh
<clpp/generated/instances.clh> Instance classes instances.clh
<clpp/datatypes.clh> Vector3, CFrame, string_concat datatypes.clh
<clpp/libs/janitor.clh> IntelliSense and require Janitor janitor.clh
<clpp/libs/dataservice.clh> DataService dataservice.clh

Quoted includes: same stem as the .clpp is inlined; any other name becomes require.
