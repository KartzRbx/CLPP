Signals

signal<T...> is a typed BindableEvent (__signal() in emitted Luau).

CL++ Meaning Page
name::Fire(...) send Fire
name~>Connect(fn) listen (Janitor) Connect
name~>Once(fn) listen once (Janitor) Once
name::Wait() yield until the next fire Wait
obj::GetPropertyChangedSignal("X") Instance property changes GetPropertyChangedSignal

Subscribe until Disconnect. Prefer ~>Connect so Janitor owns the connection.

Syntax: name::Connect(fn); · name~>Connect(fn);

Emit: name:Connect(fn) or janitor:Add(..., "Disconnect")
