Grammar (EBNF)

Reference grammar for the parser (src/core/parser/parser.cpp). The guide explains each construct with examples; this page gives its formal shape. Literals and tokens are described in Lexer.

Notes

Section titled “Notes”
  • Every block uses braces; there is no brace-free if.
  • ++ and -- as statements change the variable; in an expression they return the postfix value.
  • An (x => expr) lambda can only be called where it is written.
  • An imported module contains declarations and const NAME = literal; only; see Modules.
