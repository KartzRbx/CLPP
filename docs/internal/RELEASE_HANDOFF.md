## Author clarification: modules and exports (2026-10-11)

Local paths resolve relative to the file containing the import, following the relative-import model of TypeScript. Exports are explicit: `export def Player`, `export int Add(...)`, `export const int LIMIT = 100`. Declarations without `export` are internal to their module. Implement this uniformly for data definitions, aliases, functions, constants, diagnostics, and editor visibility; no headers or alternate return-type position.
