# Combat: referência de linguagem do autor

O arquivo Combat.clp preserva o código enviado pelo autor. A sintaxe nele é a referência principal para a revisão do site. Os marcadores NOVO e VERIFICAR descrevem trabalho pendente e não são validação do compilador.

Decisões confirmadas: sem headers; declarações por tipo ou auto; const para imutabilidade; sem let ou mut na linguagem pública. O site descreve primeiro esta linguagem, com status claro dos recursos pendentes. A atualização do compilador vem após a revisão do site.

O status público está em docs/reference/status.md. Testes executáveis e exemplos de sintaxe alvo são contados separadamente.
