A instalação isolada e o pacote ZIP passaram fora do checkout com somente DLLs do Windows. Os dois testes do instalador de editores passaram. VS Code 0.10.5 e Zed receberam as APIs gerais. A validação instrumentada completa, a integração do site e a publicação/CI no GitHub ainda estão sendo concluídas.
