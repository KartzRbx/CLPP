Showcase

Section titled “Showcase”

link @clpp… is the standard library. link @game… is a Rojo DataModel path and becomes GetService plus require. @server / @client are checked against the file tag. A Client file that calls Save is CLUAU_AUTH001, and the compiler does not emit Luau.

Pipeline

Section titled “Pipeline”
flowchart LR
src[“.clpp source”] —> cst[“rowan CST”]
cst —> ty[“clpp_ty AUTH and PAR”]
ty —> luau[“Luau”]
luau —> rojo[“Rojo / Cluaupp”]
cst —> lsp[“LSP completion”]

CL++ is the language and the compiler. Cluaupp is the Roblox host: project layout, Rojo, and the engine registry. clpp does not ship a bytecode VM.
