## How the compiler sits in a project

<pre class="mermaid">
flowchart LR
  src[".clpp / .clh / .clp"] --> pest["Pest grammar"]
  pest --> mods["import graph"]
  mods --> check["TypeId check"]
  check --> luau["Luau emit"]
  luau --> rojo["Rojo / Cluaupp"]
  src --> lsp["Editor pack + LSP"]
</pre>

CL++ is the **language**. [Cluaupp](https://github.com/KartzRbx/Cluaupp) owns engine headers, Rojo, and project `init`. There is no bytecode VM — `clpp` writes Luau files.

## Two accessors to remember

| You write | You mean |
| --- | --- |
| `player.Name` / `player.Kick()` | property / instance method |
| `@this` / `@janitor` | receiver and field inside `Class::Method` |
| `players.PlayerAdded~>Connect` | Janitor connection |
| `import { Wallet } from "./…"` | language module |
| `Player player` | Instance of class Player |
