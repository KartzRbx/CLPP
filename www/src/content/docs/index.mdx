## Showcase

```clpp
link @clpp.roblox;
link @clpp.libs.janitor as Janitor;
link @game.ReplicatedStorage.Modules.Combat as Combat;

struct Session {
    Janitor janitor;
    optional<Player> player;
    void Bind(Player player);
};

void Session::Bind(Player player) {
    @player = Some(player);
    @janitor.Add(player);
    Combat.Start(player);
}

[[server]]
void Save(Session session);

[[client]]
void OpenHud(Session session);

void init() {
    Players players = GetService<Players>();
    Session session;
    session.janitor = new Janitor();
    players.PlayerAdded~>Connect(func (Player player) {
        session.Bind(player);
        Save(session);
    });
}
```

`link @clpp…` is the standard library. `link @game…` is a Rojo DataModel path and becomes `GetService` plus `require`. `[[server]]` / `[[client]]` annotate the execution context. Runtime guards are emitted when the module file has no server/client tag.

## Pipeline

<pre class="mermaid">
flowchart LR
  src[".clpp source"] --> ast["Pest / AST"]
  ast --> bind["Two-pass binding"]
  bind --> ty["Type checker"]
  ty --> luau["Luau emitter"]
  luau --> rojo["Rojo / Cluaupp"]
  cst --> lsp["LSP completion"]
</pre>

CL++ is the language and the compiler. [Cluaupp](https://github.com/KartzRbx/Cluaupp) is the Roblox host: project layout, Rojo, and the engine registry. `clpp` does not ship a bytecode VM.

## Accessors

| You write | You mean |
| --- | --- |
| `player.Name` / `player.Kick()` | property / instance method |
| `@this` / `@janitor` | receiver and field inside `Class::Method` |
| `players.PlayerAdded~>Connect` | Janitor connection |
| `link "./Wallet.clp" as Wallet` | language module |
| `Player player` | instance of class Player |
